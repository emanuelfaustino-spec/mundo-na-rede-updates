# Mundo na Rede — Atualizações

Canal público de distribuição do aplicativo Mundo na Rede.

Este repositório contém o manifesto e os binários Windows, cuja integridade é
verificada por SHA-256. O código-fonte permanece no repositório privado do projeto.

## Instalar no Windows

1. Baixe o [instalador do Mundo na Rede](https://raw.githubusercontent.com/emanuelfaustino-spec/mundo-na-rede-updates/main/releases/Mundo-na-Rede-Setup-v0.2.5.exe).
2. Abra o arquivo baixado e siga as telas em português.
3. Leia e aceite os termos de uso para continuar.
4. Ao terminar, pesquise **Mundo na Rede** no Menu Iniciar do Windows.

O instalador cria a entrada no Menu Iniciar e o desinstalador padrão do Windows.
